## Data sources

- Public medical guidelines (WHO / China NHC / UpToDate / AAP)
- General medical consensus
- Industry controversy summary

## Not included

- Specific family / personal data → **NOT in this project** (stays in local notes, never enters git)
- Any medical insurance number / ID / home address
- Specific doctor names (unless as general reference)
- Specific hospital names
- Specific baby / mom names
